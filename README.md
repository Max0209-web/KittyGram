# KittyGram — поиск потерявшихся котов

Учебная full-stack работа на Django REST Framework и React. Здесь предметная область — объявления о потерявшихся и найденных котах: статусы, район, контакт и группы поиска.

Этот репозиторий отличается от [kittygram-platform](https://github.com/Max0209-web/kittygram-platform), где реализован каталог питомцев. В основной клиентской витрине я показываю ботов, интеграции и сайты; эту работу оставляю как пример развития full-stack навыков.

Локальная SQLite-база исключена из текущей версии. После установки создайте свою базу миграциями; учётные данные и токены нельзя хранить в Git. Ранние коммиты могут содержать прежний файл БД.

## Описание учебного проекта

# Kittygram Lost Cats

Курсовой проект по теме: разработка и развертывание REST API-сервиса для отображения котов-потеряшек в рамках проекта Kittygram на основе Django Rest Framework.

В проекте реализован сервис, где можно публиковать объявления о потерянных и найденных котах. Пользователь может зарегистрироваться, получить токен, добавить объявление, указать место, статус, контакт для связи и описание. Также есть группы поиска, которые помогают объединять объявления по району или статусу.

## Что входит в проект

`kittygram_backend` — серверная часть на Django Rest Framework.

`kittygram_frontend` — клиентская часть на React.

`Курсовая_потеряшки_с_доработками.docx` — отчет по курсовой работе.

В backend добавлены модели, сериализаторы, права доступа, API-эндпоинты, документация в README, схема `schema.yaml` и Postman-коллекция для проверки запросов.

## Основные возможности

Регистрация и авторизация пользователя по токену.

Создание, просмотр, изменение и удаление объявлений о котах.

Статусы объявлений: потерян, найден, вернулся домой.

Указание района, контакта и описания для каждого объявления.

Создание групп поиска и добавление объявлений в группы.

Проверка прав доступа: обычный пользователь изменяет только свои записи, администратор может управлять всеми.

## Запуск backend

```bash
cd kittygram_backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

После запуска API будет доступно по адресу:

```text
http://127.0.0.1:8000/api/
```

## Запуск frontend

```bash
cd kittygram_frontend
npm install
npm start
```

Frontend запускается по адресу:

```text
http://localhost:3000/
```

## Docker

Для запуска backend через Docker используется файл `docker-compose.yml`.

```bash
cd kittygram_backend
docker-compose up --build
```

Перед запуском нужно создать `.env` по примеру `.env.example`. Реальный `SECRET_KEY` не нужно публиковать в репозитории.

## API-документация

В папке backend есть файл `schema.yaml`. Его можно открыть через Swagger Editor или Redoc.

Также есть Postman-коллекция `kittygram_collection.json`, где собраны основные запросы для проверки работы API.
